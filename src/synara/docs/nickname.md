# Nicknames

## Purpose

The Nickname feature allows members to choose how SYNARA addresses them during conversations.

## How It Works

Members can provide a preferred nickname using the `!nickname` command.

Once a nickname has been saved, SYNARA will use it when referring to that member whenever appropriate.

Running the command again replaces the existing nickname.

Running the command without providing a nickname removes the saved nickname and restores normal name handling.

## Commands

`!nickname <nickname>`

Sets or updates your preferred nickname.

`!nickname`

Removes your saved nickname.

## Notes

- Nicknames are shared across every server where both you and SYNARA are present.
- Nicknames should remain appropriate for all audiences.
- SYNARA may reject nicknames that violate community standards.
