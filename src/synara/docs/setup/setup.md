# SYNARA Setup Guide

## Welcome

Welcome to the SYNARA Setup Wizard.

This guide will walk you through configuring your server one step at a time. No prior experience is required, and most servers can complete the entire setup process in less than **15 minutes**.

During setup, I'll help configure your server's required channels, roles, users, and available features.

## Before You Begin

Before enabling features, make sure your server contains any channels and roles you intend to use.

Some features require specific channels, roles, or users to function correctly.

As you progress through setup, I'll explain what each feature requires and guide you through the configuration process.

## Configuration

Throughout setup you'll use Discord's slash (`/`) commands to configure your server.

Each step builds on the previous one until your server has been fully configured.

If setup is interrupted for any reason before completion, no changes will be saved and the setup process must be started again.

## Helpful Commands

At any time you can review your server's configuration using:

`/features`

Displays every available feature and its current status.

`/settings`

Displays your server's current configuration.

`/commands`

Displays the available SYNARA commands for your server.

## Getting Started

When you're ready, continue through the setup wizard.

I'll guide you through every required step, explain each feature as it's introduced, and verify your selections before saving your server's configuration.

Let's get your community up and running.
