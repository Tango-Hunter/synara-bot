# Knowledge Base

## Purpose

The Knowledge Base is SYNARA's built-in documentation system.

It provides a central location where members and administrators can learn about available features, commands, and server configuration without needing to leave Discord.

As SYNARA continues to grow, the Knowledge Base will grow alongside her, providing up-to-date documentation for every major feature.

## How It Works

Documentation is organized into easy-to-read guides covering community features, administrator tools, server configuration, and future updates.

Members can quickly look up information without searching through previous messages or external websites.

Future versions of SYNARA will include a `/docs` command that allows documentation to be viewed directly from Discord.

## Commands

`/docs`

Browse SYNARA's available documentation.

*This command is planned for a future update.*

## Notes

- Documentation is bundled directly with SYNARA and updates automatically when new versions are released.
- New features will include documentation as part of each release.
- Administrators will automatically receive notifications when documentation is updated.
- The Knowledge Base is intended to become the primary reference for using and configuring SYNARA.
