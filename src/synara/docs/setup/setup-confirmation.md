# SYNARA Setup Complete

## Congratulations

Congratulations! SYNARA has been successfully configured for your server and is now ready to begin assisting your community.

Thank you for taking the time to complete the setup wizard. The configuration you selected has been saved and is now active for this server.

## Managing Your Server

Your server configuration can be viewed at any time using the following commands:

- `/settings` — View your server's current SYNARA configuration.
- `/features` — View which features are currently enabled or disabled.
- `/feature` — Enable or disable features at any time after setup.

Changes made using these commands take effect immediately and do not require you to run the setup wizard again.

## Documentation

SYNARA includes many built-in features that are available immediately without additional configuration.

To learn more about any feature, use:

- `/docs`

The documentation provides detailed information about available commands, feature behavior, configuration requirements, and best practices.

## Additional Commands

To view every command currently available on your server, use:

- `/commands` — Administrative commands
- `!commands` — Community commands

These command displays both administrative and community commands that are available based on your current server configuration.
