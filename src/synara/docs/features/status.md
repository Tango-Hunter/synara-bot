# System Status

## Purpose

The Status feature allows members to quickly check whether SYNARA and her connected services are operating normally.

## How It Works

When a member uses the `!status` command, SYNARA generates a current system status report.

The report provides useful diagnostic information about her operational state and can help determine whether a service interruption has occurred.

## Commands

`!status`

Displays SYNARA's current operational status.

## Notes

- Status reports are available to all members.
- This command is useful when troubleshooting unexpected behavior.
- If a service is unavailable, the status report may help identify the affected system.
