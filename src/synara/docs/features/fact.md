# Facts

## Purpose

The Fact feature lets members discover interesting real-world facts while hearing SYNARA's own perspective on what makes each fact interesting.

## How It Works

When a member uses the `!fact` command, SYNARA generates a factual piece of information and follows it with her own commentary or observation.

Every response is intended to be both informative and entertaining.

## Commands

`!fact`

Generates a random fact.

## Notes

- Facts cover a wide variety of subjects.
- SYNARA's commentary is intended to add personality to each response.
