# Custom Embeds

## Purpose

The Custom Embed feature allows administrators to create professional-looking announcements and informational messages that appear as though they were posted directly by SYNARA.

## How It Works

Administrators can use the `/embed` command to create a custom embed in the channel where the command is used.

Before the embed is posted, SYNARA generates a private preview allowing the administrator to review the message.

The administrator may then either approve the embed for posting or cancel the operation.

This approval process helps prevent mistakes and ensures the final message appears exactly as intended.

## Commands

`/embed`

Creates a custom embed in the current channel.

## Notes

- Embeds are posted in the same channel where the command is used.
- Every embed includes a private approval step before being published.
- Cancelling the preview prevents the embed from being posted.
