# Moderator Applications

## Purpose

The Moderator Application system provides a structured and private way for members to apply for a moderator position within the server. Applications are submitted directly to the server's administration team for review.

## How It Works

When moderator applications are open, eligible members may complete a fifteen-question application.

The application is divided into three sections containing five questions each, allowing applicants to complete the process in a structured manner.

Once submitted, the completed application is delivered to a private review channel where only authorized server administrators can access and review it.

Applications may be opened or closed by administrators at any time.

Users who have previously served as moderators are not permitted to submit another application.

Administrators may also maintain a blacklist of users who are not permitted to apply.

## Commands

`/modapps Open`

Opens moderator applications.

`/modapps Close`

Closes moderator applications.

`/modapps Blacklist Add`

Prevents a user from submitting future applications.

`/modapps Blacklist Remove`

Removes a user from the application blacklist.

`/modapps Blacklist List`

Displays all currently blacklisted users.

## Notes

- Applications contain fifteen questions divided into three sections.
- Submitted applications remain private and are only visible to server administrators.
- Previous moderators are not eligible to reapply.
- Blacklisted users cannot submit moderator applications.
