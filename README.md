# SYNARA Bot
SYNARA Bot is the core backend service powering the SYNARA ecosystem. This repository contains the infrastructure and automation pipeline responsible for Discord monitoring, AI-assisted response generation, event handling, and real-time community interaction.  
The system is designed to run on Railway and acts as the bridge between Discord activity and the SYNARA personality framework.

## Environment Variable Configuration
This project uses environment variables for sensitive credentials and runtime configuration.  
Examples include:  
* Discord Bot Token  
* OpenAI API Key  
* Guild / Channel IDs  
* Railway Configuration Values  
A local .env file should never be committed to source control.
